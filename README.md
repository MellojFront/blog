# Запуск сервера 

из backend:
`uv run fastapi dev src/blog/main.py`



## Стек технологий


| Слой | Инструмент | Почему это лучший выбор для практики |
| :--- | :--- | :--- |
| **Бэкенд** | `FastAPI` | Уже выбран. Пакет `fastapi[standard]` сразу ставит сервер `uvicorn` и шаблонизатор `Jinja2`. |
| **База данных** | `sqlite3` (встроен) или `aiosqlite` | Не нужно поднимать Docker с PostgreSQL. Вся база хранится в одном файле `blog.db`. Можно обойтись чистым SQL без ORM (`SQLAlchemy`), чтобы не усложнять проект. |
| **Шаблоны** | `Jinja2` | Позволяет рендерить HTML прямо на сервере и отдавать готовые куски верстки. |
| **Интерактивность** | `HTMX` | Подключается одной строкой в `<head>` через CDN. Позволяет делать SPA-переходы (открытие статьи, добавление поста без перезагрузки страницы) через HTML-атрибуты без написания JavaScript. |
| **Стили (CSS)** | `Pico.css` | Подключается через CDN. Автоматически делает стандартные теги (`<article>`, `<form>`, `<button>`) красивыми и адаптивными без единого класса в HTML. |
