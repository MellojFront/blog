# Personal Blog (Pet Project)

Минималистичный веб-блог на Python с использованием FastAPI, SQLite, Jinja2, pico css, htmx.

## Стек технологий

* **Backend:** Python 3.12+, FastAPI
* **База данных:** SQLite (`sqlite3`, связь многие-ко-многим для постов и тегов)
* **Frontend:** Jinja2, Pico.css, htmx
* **Менеджер пакетов:** uv

## Структура проекта

```text
backend/
├── pyproject.toml
├──.gitignore
├──uv.lock
├──pyproject.toml
└── src/
    └── blog/
        ├── main.py          # Маршруты FastAPI и логика фильтрации
        ├── db.py            # Контекстный менеджер и SQL-запросы к SQLite
        ├── posts_db.db      # Файл базы данных SQLite
        ├── models.py        # Модели для Pydantic, будущей архитектуры
        ├── static/          # Статические файлы (CSS - компоненты)
        └── templates/       # HTML-шаблоны Jinja2
```

## Запуск проекта

1. Установите зависимости и синхронизируйте окружение через `uv`:
```bash
uv sync
```

2. Запустите сервер разработки из директории `backend/`:
```bash
uv run uvicorn blog.main:app --reload
```

После запуска приложение будет доступно по адресу: `http://127.0.0.1:8000`  
JSON API со списком всех постов: `http://127.0.0`
