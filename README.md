# Personal Blog (Pet Project)

Минималистичный веб-блог на Python с использованием FastAPI, SQLite, Jinja2, Pico.css и HTMX.

## Стек технологий

* **Backend:** Python 3.12+, FastAPI, Markdown, Bleach
* **База данных:** SQLite (`sqlite3`, связь многие-комногим для постов и тегов)
* **Frontend:** Jinja2, Pico.css, HTMX, Vanilla JS
* **Менеджер пакетов:** uv

## Структура проекта

```text
backend/
├── .gitignore
├── pyproject.toml
├── uv.lock
└── src/
    └── blog/
        ├── main.py          # Маршруты FastAPI, фильтры Jinja2 и логика поиска
        ├── db.py            # Контекстный менеджер и SQL-запросы к SQLite
        ├── posts_db.db      # Файл базы данных SQLite
        ├── models.py        # Модели Pydantic для будущей архитектуры
        ├── static/          # Статические файлы (CSS, изображения, аватарки)
        └── templates/       # HTML-шаблоны и переиспользуемые компоненты Jinja2
```

## Запуск проекта

1. Перейдите в директорию `backend/` и синхронизируйте окружение через `uv`:
```bash
uv sync
```

2. Запустите сервер разработки из директории `backend/`:
```bash
uv run uvicorn blog.main:app --reload
```

После запуска приложение будет доступно по адресу: `http://127.0.0.1:8000`  
JSON API со списком всех постов: `http://127.0.0`

## Реализованный функционал

- [x] Полный CRUD для постов: создание, чтение, редактирование и удаление (`Create`, `Read`, `Update`, `Delete`)
- [x] Отдельная страница для каждого поста (`/posts/{post_id}`) с модальными окнами управления
- [x] Нормализованная БД для тегов (`posts`, `tags`, `post_tags`) с автоматической очисткой неиспользуемых тегов
- [x] Интерактивный ввод тегов-капсул с автогенерацией цвета и подсказками существующих тегов
- [x] Редактор текста в стиле Obsidian с панелью быстрых кнопок, горячими клавишами и мгновенным предпросмотром
- [x] Безопасный парсинг Markdown и разрешённых HTML-тегов (`markdown` + `bleach`)
- [x] Фильтрация постов по тегам и поиск по заголовку/тексту
- [x] Правый сайдбар с облаком тегов и главная страница с блоками «Свежее» и «Сейчас (Now)»
- [x] Переключение светлой и тёмной темы с сохранением выбора в `localStorage`
